# 🔐 Password Validator

A simple Java console application that validates user passwords based on basic security requirements. The program helps users create stronger passwords by checking for length, uppercase letters, and numeric digits.

---

## 📌 Project Overview

Password security is an essential part of protecting personal accounts and sensitive information. This project demonstrates how password validation can be implemented using Java using basic programming concepts such as loops, methods, conditional statements, and character validation.

The application continuously prompts the user to enter a password until all validation rules are satisfied.

---

## ✨ Features

✅ Minimum password length validation (8 characters)

✅ Checks for at least one uppercase letter (A–Z)

✅ Checks for at least one numeric digit (0–9)

✅ Displays user-friendly error messages

✅ Repeatedly prompts the user until a valid password is entered

✅ Simple and beginner-friendly Java implementation

---

## ⚙️ Validation Rules

A valid password must:

* Be at least 8 characters long
* Contain at least one uppercase letter
* Contain at least one digit
